# v8.1.5.6 — Pre-OCR UI and Audio Cleanup

This is the last UI/UX cleanup pass before starting the OCR/Import milestone.

## Changed

- Reordered tabs to match the real workflow:
  1. Single flashcard
  2. Batch / Queue
  3. Grammar
  4. Speech / Audio
  5. Fix Cards
  6. Practice & Print
  7. Conversation Practice
- Renamed the top provider label from **AI provider** to **Card AI provider**.
- Renamed the audio tab provider from **TTS provider** to **Audio provider**.
- Added a short explanation that the Audio provider is used only for audio/TTS, while card text is generated by the Card AI provider.
- Improved Speech / Audio readability:
  - Added a dedicated **Audio scan** summary line.
  - Added a dedicated **Audio status** line instead of squeezing long status text into the action bar.
  - Renamed **Clear** to **Deselect all**.
  - Added **Clear results** for clearing the current audio scan list.
  - Improved dark-theme contrast for completed/disabled audio rows.
  - Shows an empty-state message when no audio scan is loaded.
- Kept OCR out of this version. OCR/Import starts in v9.

## Not changed

- No OCR provider was added yet.
- No Piper/Ollama workflow was added.
- No new Anki note type was introduced.

## Suggested smoke tests

1. Open the app and confirm tab order.
2. Confirm the top bar says **Card AI provider**.
3. Open Speech / Audio and confirm it says **Audio provider**.
4. Click **Find missing audio** and check that summary/status are readable.
5. Check **Deselect all** and **Clear results** behavior.
