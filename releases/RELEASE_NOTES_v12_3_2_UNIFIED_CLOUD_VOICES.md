# v12.3.2 — Unified OpenAI and Gemini Voice Library

## User-facing changes

- Voice Library now includes Piper, OpenAI, Gemini and ElevenLabs in one browser.
- OpenAI exposes the full built-in TTS voice list used by the current Speech API.
- Gemini exposes all 30 documented TTS voices and their style descriptors.
- OpenAI/Gemini previews use the editable Voice Lab preview text and play inside the application.
- Built-in cloud voices do not need to be downloaded; choose **Use selected** to make them active.
- Conversation audio is synchronized with the selected cloud voice.

## Notes

OpenAI and Gemini previews are real TTS requests using the user's own API key, so normal provider usage/costs apply.
