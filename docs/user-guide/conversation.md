# Conversation

**Conversation Practice** uses the active Learning Profile and can run from a free topic or flashcard-based context.

A typical session is:

1. choose a conversation mode,
2. receive a question,
3. type or record an answer,
4. edit an STT transcript if needed,
5. request feedback,
6. continue the conversation,
7. optionally reuse useful expressions in the flashcard workflow.

Speech-to-text fills an editable textbox; transcription is not treated as immutable input.

See [Speech-to-Text](../configuration/stt.md) for provider configuration.
