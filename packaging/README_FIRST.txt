AI ANKI LANGUAGE ASSISTANT — WINDOWS TEST BUILD

1. Extract the whole ZIP to a normal writable folder.
   Example: C:\Users\YourName\Desktop\AI Anki Language Assistant

2. Do NOT move only the EXE out of the folder.
   This is a one-folder test build and the files next to the EXE are required.

3. Install Anki Desktop:
   https://apps.ankiweb.net/

4. Install AnkiConnect in Anki:
   Tools -> Add-ons -> Get Add-ons
   Code: 2055492159

5. Start:
   AI Anki Language Assistant.exe

6. Recommended setup:
   - Hybrid / BYOK
   - OpenAI
   - Local Whisper
   - Piper voice from Speech & Audio -> Voice Library

OpenAI API key:
https://platform.openai.com/api-keys

Gemini alternative:
https://aistudio.google.com/apikey

Manual:
https://paulinap92.github.io/ai-anki-language-assistant/

IMPORTANT
- Python is NOT required on the user's computer.
- Whisper's speech model is NOT included in this ZIP. It is downloaded when needed.
- Piper voice models are NOT included in this ZIP. Download one from Voice Library.
- Keep the whole extracted application folder together.
